# KNN и нейрон на MNIST - с нуля

Учебный ML-проект: KNN и нейронная сеть реализованы вручную и последовательно ускорены - от чистого Python до NumPy и Numba.

## Ноутбуки

- **`KNN.ipynb`** - K-ближайших соседей (`k=3`): наивная реализация, NumPy-векторизация, Numba и замеры скорости.
- **`Neurons.ipynb`** - перцептрон с сигмоидой (AND / OR) и сеть из 10 нейронов (one-vs-all) для распознавания цифр.

## Результаты

KNN на подвыборке 1 000 обучающих / 200 тестовых примеров:

| Реализация | Точность | Время |
|---|---:|---:|
| Чистый Python | 91.50 % | 63.19 с |
| NumPy | 90.00 % | 2.18 с |
| Numba | 90.00 % | 5.41 с |

NumPy ускоряет вычисления в **29 раз**. Небольшая разница в точности вызвана разным выбором соседей при равных расстояниях.

На полной выборке (60 000 / 10 000) Numba с `float32` даёт **97.11 %** за ~54 с.

Нейросеть на MNIST: **87.80 %** на 1 000 тестовых примеров, MSE снижается с 0.0431 до 0.0153 за 10 эпох.

## Запуск

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
jupyter lab
```

Ноутбуки можно выполнять сверху вниз. При первом запуске MNIST скачается автоматически (~55 МБ).

## Файлы

```
KNN.ipynb         # KNN: Python → NumPy → Numba
Neurons.ipynb     # перцептрон и классификатор цифр

.gitignore
```

Требования: Python 3.11+ (проверено на 3.14.5), NumPy, scikit-learn, pandas, Matplotlib, Numba, JupyterLab.
